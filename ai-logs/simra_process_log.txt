CODE SNIPPET USED:
```javascript
function Navbar({ active }) {
  const navigate = useNavigate();
  return (
    <nav style={nav.bar}>
      <span style={nav.brand} onClick={() => navigate("/dashboard")}>
        <span style={nav.dot} />
        MoodTunes
      </span>
      <div style={nav.links}>
        {["Dashboard","Library","Friends","History"].map((l) => (
          <span
            key={l}
            onClick={() => navigate("/" + l.toLowerCase())}
            style={{
              ...nav.link,
              color: active === l ? "#fff" : "rgba(255,255,255,0.4)",
              fontWeight: active === l ? 700 : 500,
            }}
          >
            {l}
          </span>
        ))}
        <span style={{ ...nav.link, color: "rgba(255,255,255,0.4)" }}>Logout</span>
      </div>
    </nav>
  );
}
```

- Navbar was not appearing on the page even though the code was in the file
- Debugging revealed the return statement was missing the "return" keyword — 
  the JSX was just a floating expression with no return statement

HOW I FIXED IT:
- Found the missing return keyword in the DashboardPage return statement
- Changed bare `(` to `return (` on the correct line
- Browser hot-reloaded and navbar appeared immediately after saving
